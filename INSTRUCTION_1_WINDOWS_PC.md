# 📱 Инструкция №1: Быстрая настройка телефона через компьютер (Windows)

> **Для кого:** Для сотрудника, у которого есть компьютер/ноутбук на Windows (10 или 11) и обычный USB-кабель.  
> **Время настройки одного телефона:** ~15–30 секунд.  
> **Нужен ли Python или сложный софт:** НЕТ. Скрипт сам скачает всё необходимое.

---

## ШАГ 1. Подготовка на компьютере (делается один раз)

1. Скачайте папку с файлами на компьютер (или распакуйте полученный ZIP-архив, например, на **Рабочий стол**).
2. Внутри папки должны быть файлы:
   * `run_windows.bat` — **главный запускатор**
   * `provision.ps1` — файл логики
   * `HEAD_2026.10.08_release.apk` — приложение (установится само, если на телефоне его ещё нет)

---

## ШАГ 2. Включение «Отладки по USB» на телефоне

Чтобы компьютер мог выдать разрешения приложению, на телефоне нужно включить сервисный режим:

### 2.1. Включаем режим разработчика
1. Откройте **«Настройки»** телефона.
2. Пролистайте в самый низ до пункта **«Об устройстве»** (или *«О телефоне»*).
3. Найдите строку **«Номер сборки»** (на Xiaomi/Realme иногда нужно сначала нажать *«Версия»*).
4. **Быстро нажмите на «Номер сборки» 7 раз подряд.**  
   *Телефон напишет: «Вы стали разработчиком!» (если на телефоне стоит графический ключ или пароль — введите его).*

```text
┌──────────────────────────────────────────────────┐
│  Настройки -> О телефоне                         │
│                                                  │
│  Модель: realme RMX3938                          │
│  Версия Android: 15 / 16                         │
│  Номер сборки: RMX3938_14.0.1...  ◄─── ТАПНУТЬ 7 │
│                                         РАЗ СЮДА │
│  [ Сообщение: "Вы стали разработчиком!" ]        │
└──────────────────────────────────────────────────┘
```

### 2.2. Включаем тумблер отладки
1. Вернитесь в главное меню **Настроек**.
2. Перейдите в **«Система»** (или *«Дополнительные настройки»* / *«Специальные возможности»*).
3. Откройте новый пункт: **«Для разработчиков»** (Developer options).
4. Найдите и включите пункт **«Отладка по USB»** (USB Debugging).
5. Нажмите **«ОК»** в окне предупреждения.

```text
┌──────────────────────────────────────────────────┐
│  Для разработчиков                               │
│                                                  │
│  Память ...                                      │
│  Заводская разблокировка ...                     │
│                                                  │
│  ОТЛАДКА                                         │
│  Отладка по USB                     [  ВКЛ  ● ]  │
│  Разрешить отладку при подключении       ▲       │
│  к USB                                   │       │
│                             ВКЛЮЧИТЬ ЭТОТ ТУМБЛЕР│
└──────────────────────────────────────────────────┘
```

> **Особенность для Xiaomi / HyperOS / Redmi / POCO:**  
> Входить в Mi-аккаунт и вставлять SIM-карту **НЕ НУЖНО**! Если скрипт обнаружит блокировку настроек по USB, он сам вежливо попросит:  
> *«Нажмите в шторке телефона на "Зарядка через USB" и выберите "USB-модем"»*.  
> Как только вы нажмете «USB-модем», скрипт мгновенно обойдет китайскую защиту и применит все настройки.

---

## ШАГ 3. Запуск скрипта на компьютере

1. На компьютере дважды кликните по файлу **`run_windows.bat`**.
2. Откроется черное окно консоли.  
   *(Если на компьютере ещё не было утилит Android, скрипт за 5 секунд сам скачает их от Google).*
3. В окне появится строка:
   ```text
   [...] Ожидаю подключения телефона по USB (с включенной отладкой по ADB)...
   ```

---

## ШАГ 4. Подключение кабеля и подтверждение ключа

1. Подключите телефон к компьютеру через USB-кабель.
2. **Разблокируйте экран телефона!**
3. На экране смартфона появится всплывающее окно:

```text
┌────────────────────────────────────────────────────────┐
│  Разрешить отладку по USB?                             │
│                                                        │
│  Цифровой отпечаток ключа RSA компьютера:              │
│  4A:7B:9C:12:34:56:78:90:AB:CD:EF:12:34:56:78:90       │
│                                                        │
│  [✔] Всегда разрешать с этого компьютера  ◄── ОБЯЗАТЕЛЬНО│
│                                               ПОСТАВИТЬ│
│                                                        │
│            [ Отмена ]          [ РАЗРЕШИТЬ ]  ◄── НАЖАТЬ│
└────────────────────────────────────────────────────────┘
```

4. **ОБЯЗАТЕЛЬНО поставьте галочку** *«Всегда разрешать с этого компьютера»* и нажмите **«РАЗРЕШИТЬ»**.

---

**Телефон готов к работе!**  
* Выдерните провод из этого телефона.
* Окно на компьютере **закрывать не нужно** — просто вставьте провод в следующий телефон, подтвердите отладку на его экране, и он настроится так же автоматически.
