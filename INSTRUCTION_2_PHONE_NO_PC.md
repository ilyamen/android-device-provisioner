# 📲 Инструкция №2: Настройка прямо с телефона БЕЗ компьютера (в полях)

> **Для кого:** Для сотрудника, у которого **нет под рукой компьютера**, а есть только сам смартфон Android (версии 11, 12, 13, 14, 15 или 16).  
> **Время настройки:** ~2–3 минуты.  
> **Что потребуется:**  
> 1. Подключение к любой сети **Wi-Fi** (можно просто раздать интернет со своего личного телефона через «Точку доступа»).  
> 2. Два бесплатных приложения: **Shizuku** и **aShell** (их можно скачать из Google Play или заранее передать APK-файлами).

---

## ШАГ 1. Подключение к Wi-Fi

> ⚠️ **Важно:** Функция «Беспроводная отладка» в Android работает **только при активном Wi-Fi**. На обычном мобильном 4G/5G интернете система включить её не даст.

* Подключите настраиваемый телефон к офисному Wi-Fi.
* **Если Wi-Fi рядом нет:** включите на втором телефоне режим **«Точка доступа Wi-Fi»** (раздача интернета) и подключите настраиваемый телефон к нему.

---

## ШАГ 2. Включение «Для разработчиков» на телефоне

1. Откройте **«Настройки»** -> **«Об устройстве»** (или *«О телефоне»*).
2. Найдите пункт **«Номер сборки»** (на ряде прошивок: *«Версия» -> «Номер сборки»*).
3. **Нажмите на него быстро 7 раз подряд**, пока не появится надпись: *«Вы стали разработчиком!»*.

---

## ШАГ 3. Связка Shizuku с телефоном через код сопряжения

1. Установите и откройте приложение **Shizuku**.
2. Найдите блок **«Запуск через беспроводную отладку»** (Start via Wireless debugging) и нажмите кнопку **«Сопряжение»** (Pairing).

```text
┌────────────────────────────────────────────────────────┐
│  Shizuku                                               │
│                                                        │
│  Запуск через беспроводную отладку                     │
│  Для Android 11+                                       │
│                                                        │
│       [ Руководство ]             [ СОПРЯЖЕНИЕ ] ◄─ ТАП│
└────────────────────────────────────────────────────────┘
```

3. Shizuku попросит открыть параметры разработчика -> нажмите кнопку **«Параметры разработчика»** (Developer options).
4. В открывшемся списке найдите пункт **«Беспроводная отладка»** (Wireless debugging) и включите тумблер.
5. **ВНИМАНИЕ! Нажмите НЕ на тумблер, а на САМ ТЕКСТ «Беспроводная отладка»**, чтобы провалиться внутрь этого меню:

```text
┌────────────────────────────────────────────────────────┐
│  Для разработчиков                                     │
│                                                        │
│  Беспроводная отладка                   [  ВКЛ  ● ]    │
│  Разрешить сетевую отладку                     ▲       │
│                                                │       │
│  ◄── НАЖМИТЕ ПРЯМО НА ЭТУ СТРОКУ (НА ТЕКСТ) ───┘       │
└────────────────────────────────────────────────────────┘
```

6. Внутри открывшегося экрана нажмите: **«Подключить устройство с помощью кода сопряжения»** (Pair device with pairing code).
7. На экране появится окно с 6 цифрами (код сопряжения):

```text
┌────────────────────────────────────────────────────────┐
│  Подключение устройства                                │
│                                                        │
│  Код сопряжения Wi-Fi:                                 │
│  4 8 2 9 1 5   ◄─── ЭТОТ КОД                           │
│                                                        │
│  IP-адрес и порт: 192.168.1.45:38472                   │
│                                      [ Отмена ]        │
└────────────────────────────────────────────────────────┘
```

8. **Опустите верхнюю шторку уведомлений.** Там появится уведомление от Shizuku:  
   *«Служба сопряжения найдена. Введите код сопряжения»*.
9. Введите эти 6 цифр в строку уведомления и нажмите стрелочку отправки:

```text
┌────────────────────────────────────────────────────────┐
│  🔔 Shizuku • сейчас                                  │
│  Служба сопряжения найдена                             │
│  [ 482915             ]  [  ➔  ] ◄── ВВЕСТИ КОД И НАЖАТЬ│
└────────────────────────────────────────────────────────┘
```

10. Внизу экрана всплывет сообщение: **«Сопряжение выполнено успешно!»**.

---

## ШАГ 4. Запуск сервиса Shizuku

1. Вернитесь назад в приложение **Shizuku**.
2. В блоке «Запуск через беспроводную отладку» нажмите большую кнопку **«Запустить»** (Start).
3. По экрану пробегут строчки кода, и в самом верху появится статус:
   **«Shizuku запущен (версия 13.x.x, от имени adb)»**.

```text
┌────────────────────────────────────────────────────────┐
│  Shizuku                                      [ ● ]    │
│                                                        │
│  ✔ Shizuku запущен                                     │
│  Версия: 13.5.4 | Режим: adb                           │
│                                                        │
│  [ Управление приложениями (1) ]                       │
└────────────────────────────────────────────────────────┘
```

---

## ШАГ 5. Выдача прав через терминал aShell

1. Откройте приложение **aShell** (это легкий локальный терминал, работающий через Shizuku).
2. При первом запуске появится запрос:  
   *«Разрешить aShell доступ к Shizuku?»* -> Нажмите **«Разрешить всегда»** (Allow all the time).
3. Внизу в строке ввода команд вставьте **одну следующую строчку целиком**:

```bash
cmd appops set --user 0 com.gadgets.auto RECEIVE_SENSITIVE_NOTIFICATIONS allow && cmd notification allow_listener com.gadgets.auto/com.gadgets.auto.util.network.NotificationService 0 && dumpsys deviceidle whitelist +com.gadgets.auto
```

4. Нажмите синюю круглую кнопку со стрелочкой (или **Enter** на клавиатуре) для запуска:

```text
┌────────────────────────────────────────────────────────┐
│  aShell                                                │
│                                                        │
│  $ cmd appops set --user 0 com.gadgets.auto ...        │
│                                                        │
│  [ Команда выполнена за 0.8с ]                         │
│                                                        │
│  [ Вставьте команду сюда...              ]   [  ➔  ]   │
│                                                 ▲      │
│                                   НАЖАТЬ КНОПКУ ПУСКА  │
└────────────────────────────────────────────────────────┘
```

---

## ШАГ 6. Проверка результата

Чтобы на 100% убедиться, что всё сработало, вставьте в aShell проверочную команду:

```bash
cmd appops get --user 0 com.gadgets.auto RECEIVE_SENSITIVE_NOTIFICATIONS
```

Нажмите пуск. На экране должно появиться:
```text
RECEIVE_SENSITIVE_NOTIFICATIONS: allow
```

### 🎉 ВСЁ ГОТОВО!
* Текст `allow` означает, что Android больше никогда не будет подменять пуши TBC Bank и других банков на «Защиту конфиденциальности».
* Вы можете отключить «Беспроводную отладку» в настройках и закрыть Shizuku. Выданные разрешения намертво сохранены в памяти телефона и переживут любые перезагрузки устройства.
